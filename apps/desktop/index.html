How sync works

  • Local → cloud is near-instant: a file watcher uploads the moment you add or change a file.
  • Cloud → local is polled every ~20 seconds (Buttercloud has no push notifications yet), and also checked immediately whenever you open this app.
  • Deletes are never automatic. If a file disappears on either side, you'll see a confirmation card on the Status tab before it's removed on the other side — there's no recycle bin yet, so this is deliberately conservative.

Usage & billing

Storage, bandwidth, and invoice status live on the web dashboard — this app doesn't show them inline to avoid asking for your account password (it only ever uses a scoped API key).
